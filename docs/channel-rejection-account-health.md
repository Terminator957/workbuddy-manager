# 渠道拒绝只终止当前请求

上游返回 `11128` / `11-128` 渠道拒绝时，网关直接返回原始 HTTP 状态和错误内容，错误类型为 `channel_rejected`。不换接口、不轮换账号，也不写账号冷却、模型冷却或连败计数。请求被拒绝后，账号仍可处理其他合法请求。

此前网关会在主接口拒绝后请求备用接口。备用接口可能返回 `11102`，掩盖原始渠道拒绝。官方补丁 0018 已防止这个备用接口错误写入模型冷却；0019 进一步停止该重试链，保留真正的失败原因。

主接口直接返回的模型不可用、真实限流、余额不足及令牌失效继续按原有策略处理。此修复不会使被上游拒绝的请求变为成功。
